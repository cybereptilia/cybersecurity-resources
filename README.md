# Resources for Cybersecurity Professionals

A small blog built with [Jekyll](https://jekyllrb.com/) and published with GitHub Pages for **CECS 6230 – IT Operations** (Polytechnic University of Puerto Rico).

Live site: <https://cybereptilia.github.io/cybersecurity-resources/>

## Contents

| Post | Topic |
|---|---|
| Data Recovery | Causes of data loss, RPO and RTO, backup types, the 3-2-1 rule, recovery techniques |
| Comparison of ITIL Processes | ITIL v2, v3, and ITIL 4 compared with Schiesser's 12 systems management processes |
| Ethics, Legislation, and Outsourcing | Business ethics, SOX, GLBA, breach-notification laws, SEC rules, outsourcing |
| Paper review: Disaster Recovery Plan | Nawrocka (2026), *Safety & Defense* |
| Paper review: Incident Response Planning | Patterson, Nurse & Franqueira (2023), *Computers & Security* |

## Structure

```
_config.yml      Site settings (title, URL, theme)
index.md         Home page; lists the posts automatically
about.md         About page
resources.md     Curated links to guides, standards, and laws
_posts/          Blog posts, named YYYY-MM-DD-title.md
```

## Editing

Edit any `.md` file directly on GitHub (pencil icon) and commit. GitHub Pages rebuilds the site automatically within a minute or two.

Posts dated in the future are not published, so keep post dates on or before the current date.
